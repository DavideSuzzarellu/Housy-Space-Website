# ContactoFormas

Las cuatro formas de contacto: Llamar, WhatsApp, Email (info@housyspace.com) y Cuéntanos.

- **Dónde está en la web:** `/contacto/` (`section#formas`).
- **Hojas de estilo:** `site.css`, `v2.css`, `v3.css`, `donde.css`, `nosotros.css`, `contacto.css` (copias en `css/` de este sistema).
- **Qué aporta quien lo use:** teléfono, WhatsApp, correo y enlace al formulario.

La vista es una copia estática del marcado real de la página a 1440 px, sin JavaScript: lo que se mueve (carruseles, menús, mapas, contadores) aparece en su estado inicial.

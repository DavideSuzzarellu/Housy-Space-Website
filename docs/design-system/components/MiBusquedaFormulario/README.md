# MiBusquedaFormulario

Formulario «Mi búsqueda» en pasos (qué buscas, dónde, presupuesto, contacto) con tres consentimientos.

- **Dónde está en la web:** `/mi-busqueda/` (`section#formulario`).
- **Hojas de estilo:** `site.css`, `v2.css`, `v3.css`, `cuadricula.css` (copias en `css/` de este sistema).
- **Qué aporta quien lo use:** las opciones de cada paso.
- **Notas:** Sin IA. Hoy envía por WhatsApp o correo; preparado para digital@housyspace.com.

La vista es una copia estática del marcado real de la página a 1440 px, sin JavaScript: lo que se mueve (carruseles, menús, mapas, contadores) aparece en su estado inicial.

# NosotrosSeccion

Plantilla de las secciones de Nosotros: rótulo, frase grande, texto e ilustración propia, alternando fondo crema y blanco.

- **Dónde está en la web:** `/nosotros/` (`section#experiencia`).
- **Hojas de estilo:** `site.css`, `v2.css`, `v3.css`, `nosotros.css` (copias en `css/` de este sistema).
- **Qué aporta quien lo use:** rótulo, frase, texto e ilustración (assets/img/nosotros/ill-*.webp).

La vista es una copia estática del marcado real de la página a 1440 px, sin JavaScript: lo que se mueve (carruseles, menús, mapas, contadores) aparece en su estado inicial.

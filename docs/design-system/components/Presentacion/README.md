# Presentacion

Presentación bajo el vídeo con el titular principal de la portada («Cada rincón tiene una historia…») y el texto de quiénes somos.

- **Dónde está en la web:** `/` (`section#presentacion`).
- **Hojas de estilo:** `site.css`, `v2.css`, `v3.css`, `home-intro.css`, `acordeon5.css` (copias en `css/` de este sistema).
- **Qué aporta quien lo use:** titular y texto de presentación.
- **Notas:** El titular se anima palabra a palabra con JavaScript; usa el estilo `presentacion-h1`.

La vista es una copia estática del marcado real de la página a 1440 px, sin JavaScript: lo que se mueve (carruseles, menús, mapas, contadores) aparece en su estado inicial.

# Cifras

Banda «Cinco años de HousySpace en cifras» con las cifras redondeadas en «más de» y botón a los inmuebles vendidos.

- **Dónde está en la web:** `/` (`section#cifras`).
- **Hojas de estilo:** `site.css`, `v2.css`, `v3.css`, `home-intro.css`, `acordeon5.css` (copias en `css/` de este sistema).
- **Qué aporta quien lo use:** las cifras (+35 M€, +100 inmuebles, +10 municipios…) y sus textos.
- **Notas:** Las cifras se cuentan desde 0 con JavaScript al aparecer; la vista muestra el valor final. Siempre «más de», nunca la cifra exacta.

La vista es una copia estática del marcado real de la página a 1440 px, sin JavaScript: lo que se mueve (carruseles, menús, mapas, contadores) aparece en su estado inicial.

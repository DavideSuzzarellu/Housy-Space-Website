Logos de HousySpace, copiados tal cual de la web (assets/img/).

- `logo.svg` y `logo-oscuro.svg`: logotipo completo en tinta oscura, para papel claro (`c-bg`, `c-bg-alt`).
- `logo-blanco.svg`: logotipo en blanco, para bloques oscuros (`c-bg-dark`) y sobre fotos.
- `isotipo.svg` / `isotipo-blanco.svg`: solo el símbolo, para espacios pequeños (favicon, avatar de reseñas).
- `palabra-blanco.svg`: solo la palabra, en blanco.
- `pin-housyspace.svg`: el pin con el isotipo, para el mapa y la imagen de valoración.

# Translation glossary

Shared vocabulary for the translated copy. Spanish (`es`) is the source. Each locale owns its own section below, so edits never collide. Fixed phrases (AGENTS.md §11.5) are never translated word for word, only kept equivalent.

### Style rules

- Brand: no elision before HousySpace (aspirated h): `de HousySpace`, never `d'HousySpace`.
- Weak pronouns: `te l'expliquem` (never `te'l expliquem`), `t'ho direm` for a clause, `posar-nos en contacte amb tu` (never `contactar-te`/`et contactem`).
- Gender-neutral forms: `obert/a`, `subscrit/a`.
- Verb government: `influir en`, `consistir a`, `pensar a`.
- Address ordinals: `2n 3a`, not `2º-3ª`.

## Italian (it)

### Register

- `tu`, warm and direct, matching the Spanish tuteo. No `Lei`. Imperatives in the second person singular ("Scopri", "Raccontaci").
- Neutral wording where gender would show ("Come preferisci che ti contattiamo?", not "essere contattato").
- Say "consulenza" for the service and "consulente" for the person; "agenzia immobiliare" only where the Spanish says "inmobiliaria".
- Sentence case, no full stop on headings, `*asterisk*` emphasis on the equivalent part of the heading.

# Translation glossary

Spanish is the source (AGENTS.md section 4). One recurring concept = one term per locale, used in the dictionary (`src/shared/i18n`) and in every content file.

## English (en) — British English

| Spanish                               | English                                                                                  | Notes                                                                                                            |
| ------------------------------------- | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| consultores inmobiliarios             | real estate consultants                                                                  | Never "agency" for HousySpace itself (AGENTS.md 11.5). "Estate agency" only when contrasting ourselves with one. |

| asesoría (firm)                       | advisory firm                                                                            | e.g. tax advisory firm.                                                                                          |
